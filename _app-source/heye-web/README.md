# 禾页账本网页体验

来源为本机 shiguang-ledger 的独立网页原型（2026-11-02），与 heye-miniprogram 微信小程序分别维护。没有复制个人账目、持仓、云端记录或部署凭据。

运行 `npm test` 验证账目与状态逻辑，`npm run build` 复制网页资源到站点 `heye/`。通过 HTTP 访问 `/heye/`。

记账、账本、预算、分析、回顾和备份在当前浏览器运行。默认虚构示例与个人账本分离；切换到个人账本后从空白开始。账户界面为预览，无真实登录或云同步；图片导入为人工核对流程。静态版本未接通行情服务，相关操作显示明确提示，不请求不存在的 API。微信小程序的 OCR、微信登录与云同步不因本次网页发布而改变。

## 微信云账本接入

新增 `public/cloud.html` 云端模式入口，与原本机版分开，避免隐式覆盖或上传旧本地账目。通过小程序生成的可撤销连接码访问同一环境；网页先读云端，保存时带版本和持仓摘要，不在前端存放管理员凭据。

2026-11-14 已在既有微信体验版环境部署独立接口，并通过真实 HTTP 检查：预检 204、未签名/伪造码 401、其他来源 403。`public/cloud-config.json` 已填入接口并启用；真实账本首次连接须用户本人在小程序生成连接码，尚未代用户授权或用真实账目完成读写联调。原本机网页仍使用浏览器存储。云端模式支持收支和基金/黄金持仓的读取、增改删与备份；余额、负债、计划等扩展原样保留，不在此页面编辑。

后端与小程序开发目录：`/Users/a10013008/Desktop/个人AI项目/heye-web-cloud`，详见该目录 `docs/网页云账本接入.md`。没有自动迁移、合并或删除个人数据；授权必须由用户在小程序确认。

连接码使用服务端 HMAC 签名和可撤销授权；无管理员密钥进前端。免费方案有代码限频和事务内成功写入上限，不能保证恶意请求不消耗网关/函数免费额度；网关收费限频未开通，未升级或启用超额按量。
