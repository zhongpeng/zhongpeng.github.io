# 第八巷 · 可探索的个人主页

三维夜间旧街，三个可进入的房间，共用两项真实菜单入口：
- Moment & Forever：`/moment-forever/`
- 有数财务助手：`/money-compass/`

操作：点击地面行走、点击门自动前往并进屋，WASD/方向键移动，E 与附近门口或柜台互动，手机方向盘移动。进屋后点击菜单或走到柜台按 E；地图保留直接链接。WebGL 不可用时显示两个原应用入口。

场景由 Three.js 本地几何体与 Canvas 文字纹理构建，不依赖第三方 CDN，不使用 Blender 导出模型。房间切换采用淡入淡出。两个应用本身保持独立，主页菜单直接跳转，不修改账本数据。

`npm ci && npm test && npm run build` 生成仓库根目录 index.html 和 street-assets。

验证：导航、进出房间、菜单状态与目标链接自动检查；场景初始化测试使用真实 Three.js 几何体和模拟渲染器。该检查不等于真实浏览器 WebGL 或手机视觉验收。

## 2026-09-09：个人探索世界

主页保留人物行走和点击地面移动，五扇门分别连接旅途留影、拾光茶馆、会客厅、完整木心美术馆、山野营地。地图和柜台书页会让人物先走到指定门口。旅行相框与营地明确为待填充空间，不代表用户真实旅行记录。

新增地点：在 navigation.mjs 的 ROOMS 登记独立 id、门口坐标与场景类型；在 memory-scenes.js 增加对应场景，在 page.html 地图与书页增加同名入口。扩大街道时同步可行走边界与测试。真实地名、照片和路线由用户提供后补充。

美术馆新增两处隐藏入口：一层人物展厅发光画框通往 /moment-forever/；二层阅览厅手账通往 /money-compass/。应用路径与内容未改动。浏览器返回保留馆内位置；回到第八巷出现在美术馆门口。

验证：7 项主页导航和场景测试、16 项美术馆路线及模型对照测试。实际浏览器验证地图自动行走、山野场景、跨页入馆、手账发现与记账往返。移动真机未测。
