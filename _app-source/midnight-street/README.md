# 第八巷 · 可探索的个人主页

三维夜间旧街，三个可进入的房间，共用两项真实菜单入口：
- Moment & Forever：`/moment-forever/`
- 有数财务助手：`/money-compass/`

操作：点击地面行走、点击门自动前往并进屋，WASD/方向键移动，E 与附近门口或柜台互动，手机方向盘移动。进屋后点击菜单或走到柜台按 E；地图保留直接链接。WebGL 不可用时显示两个原应用入口。

场景由 Three.js 本地几何体与 Canvas 文字纹理构建，不依赖第三方 CDN，不使用 Blender 导出模型。房间切换采用淡入淡出。两个应用本身保持独立，主页菜单直接跳转，不修改账本数据。

`npm ci && npm test && npm run build` 生成仓库根目录 index.html 和 street-assets。

验证：导航、进出房间、菜单状态与目标链接自动检查；场景初始化测试使用真实 Three.js 几何体和模拟渲染器。该检查不等于真实浏览器 WebGL 或手机视觉验收。
