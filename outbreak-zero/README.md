# 零号蔓延 · Zero Outbreak

原创中文网页策略小游戏，借鉴传播、进化和全球应对的策略循环。不是《瘟疫公司》的完整复刻，不使用原作素材。地图、人口和模拟参数均为虚构游戏设定。

**在线试玩：https://zhongpeng.github.io/outbreak-zero/**

## 玩法

选择难度，点击地图地区开始。积累进化点，升级传播、症状和适应能力，在解药完成前让全球死亡比例达到 85%。感染者耗尽或解药完成则失败。

支持 18 个地区、8 种多级能力、3 档难度、随机事件、暂停、倍速及浏览器本地存档。空格暂停；1 / 2 / 3 切换倍速。存档仅保存在当前浏览器，不跨设备同步。

## 本地运行

直接打开 `index.html`，或在当前目录运行 `python3 -m http.server 8769 --bind 127.0.0.1`，访问 http://127.0.0.1:8769 。无需安装依赖。

## 验证

运行 `node test.cjs`：7 组规则测试、20 个种子各 600 步人口约束检查，以及 30 局标准难度策略模拟。模拟仅验证策略可行性，不代表长期游戏平衡完成。

## 文件

- `engine.js`：独立模拟引擎
- `app.js`：交互与本地存档
- `index.html` / `style.css`：原创 SVG 地图与响应式界面
- `test.cjs`：规则与模拟测试
